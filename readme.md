# BREWS Cafe Landing Page

A modern and responsive cafe website built using HTML, CSS, and JavaScript. This project showcases real-world frontend features like search functionality, category filtering, and a cart system.

## Features

- Live Search Bar
- Category Filtering (Coffee, Cold Drinks, Snacks)
- Add to Cart with localStorage
- Remove Items from Cart
- Total Price Calculation
- Responsive Design
- Clean UI with modern styling

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- localStorage
